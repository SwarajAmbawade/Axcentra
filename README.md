# Axcentra — Frontend Development Internship

A collection of projects and assignments completed during my **Axcentra Web Development Internship/Training**, documenting my progression from fundamental HTML/CSS development to JavaScript, API integration, and client-side data management.

## 📌 About

This repository contains the work completed across **4 weeks of frontend development**, with each week focusing on different web development concepts and practical implementations.

The projects were built using **HTML, CSS, and JavaScript**, with an external weather API and browser `localStorage` introduced in the later stages.

# 🖼️ Week 2 — Interactive Image Gallery

Week 2 introduced **JavaScript DOM manipulation and event handling**.

The project is an interactive image gallery where users can:

* Browse a responsive image grid
* Hover over images
* Click an image to enlarge it
* View the image inside a lightbox
* Close the lightbox

### Key Concepts

* DOM selection
* `querySelectorAll()`
* Event listeners
* Click events
* Dynamic image source changes
* CSS transitions
* Lightbox implementation

### Technologies

* HTML5
* CSS3
* JavaScript

# 🌦️ Week 3 — Weather Application

Week 3 introduced **API integration and asynchronous JavaScript**.

The Weather App allows users to enter a city and retrieve its current weather information.

### Features

* City search
* Real-time API request
* Temperature display
* Weather condition
* Humidity information
* Invalid-city handling
* API error handling
* Responsive card-based UI

### API

The application uses the **OpenWeatherMap API** to retrieve weather information.

### Concepts Learned

* `fetch()`
* REST API requests
* JSON parsing
* Promises
* DOM manipulation
* Error handling
* Dynamic content rendering

### Technologies

* HTML5
* CSS3
* JavaScript
* OpenWeatherMap API

# 👨‍🎓 Week 4 — Student Management Dashboard

Week 4 focused on **JavaScript logic, data manipulation, and browser storage**.

The Student Management Dashboard allows users to manage a list of students directly in the browser.

### Features

* Add students

* Store roll number
* Store department
* Display students in a table
* Search students by name
* Delete students

### Concepts Learned

* JavaScript objects
* Arrays
* Array methods
* `filter()`
* DOM manipulation
* Form handling
* Event listeners
* JSON serialization
* `localStorage`
* CRUD-style operations

### Technologies

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

# ▶️ How to Run

These projects are built with vanilla HTML, CSS, and JavaScript, so no package installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/SwarajAmbawade/Axcentra.git
```

### 2. Open the project

Navigate into any week's folder.

For example:

```text
Week2/assign1gallery.html
```

or

```text
Week3/index.html
```

or

```text
Week4/index.html
```

### 3. Run in a browser

Open the HTML file directly in a browser, or use **VS Code Live Server** for a better development experience.
